> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete implementation unit S02-3 by providing the canonical monotonic ULID entry point and exact-match market instrument keys.

**Architecture:** `omra.core.ids` is an L1 core module. It owns `Market`, holds one process-wide `python-ulid` 4.0.1 `ULIDGenerator`, depends only on `omra.core.errors.IdentifierError`, and exposes strict key creation/parsing with no fuzzy normalization. `omra.core` re-exports `Market`; architecture tests prevent direct ULID use elsewhere and broker account literals in core.

**Tech Stack:** Python 3.12, `python-ulid==4.0.1` from `uv.lock`, pytest, existing AST test utilities, ruff, mypy, import-linter.

## Global Constraints

- Planning documents are higher authority than design documents; the owning design document is `docs/design/02-domain-model.md`.
- Implement only S02-3 from `docs/design/17-implementation-progress.md:170`.
- `new_id() -> str` is the only internal ULID creation entry point.
- One module-scoped `ULIDGenerator()` must be reused; its default `StrictMonotonicPolicy` is required.
- `Market` values are exactly `KRX`, `NASD`, `NYSE`, `AMEX`, and `UPBIT`.
- Instrument keys use exact `"{venue}:{symbol}"` matching; no case folding, trimming, substring matching, aliases, or fuzzy matching.
- Empty symbols and any whitespace in a key or symbol raise `IdentifierError`.
- Parsing splits only at the first colon so the remaining symbol is preserved verbatim.
- No new dependencies; use the version already locked in `uv.lock`.
- Production code is written only after the new tests fail for the expected missing-module reason.

- [x] **Step 3: Implement the minimum production API**

Create `src/omra/core/ids.py` around these exact mechanics:

```python
from enum import StrEnum

from ulid import ULIDGenerator

from omra.core.errors import IdentifierError

_GENERATOR = ULIDGenerator()


class Market(StrEnum):
    KRX = "KRX"
    NASD = "NASD"
    NYSE = "NYSE"
    AMEX = "AMEX"
    UPBIT = "UPBIT"


def new_id() -> str:
    return str(_GENERATOR.generate())
```

Implement a private symbol validator that rejects non-strings, empty values, or any `str.isspace()` character with `IdentifierError`. `instrument_key` formats the exact enum value. `parse_instrument_key` rejects non-strings/whitespace, uses `partition(":")`, constructs `Market(venue)` without normalization, validates the symbol, and wraps invalid venues as `IdentifierError` with exception chaining.

Modify `src/omra/core/__init__.py` to re-export `Market` without exporting or wrapping another ULID creation path.
